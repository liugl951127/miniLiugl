# 🔥 Agent Forge V1.0 — 智能体群流水线

> 从客户需求文档到生产部署, 5 步全自动, 5 分钟上线

## 📖 产品定位

**Agent Forge** 是企业级智能体群 (Agent Group) 一站式开发与部署平台。用户通过上传客户需求文档、与 AI 对话澄清、或选择行业模板, 系统会自动:

1. **解析需求** → 提取项目类型、场景、规模、合规要求
2. **设计团队** → 推荐多智能体角色、工具集、协作流程
3. **远程部署** → 一键发布到 Docker / Kubernetes / 阿里云 / 边缘设备
4. **实时监控** → 部署阶段、容器状态、QPS 指标、告警
5. **版本管理** → 时间线、差异对比、一键回滚

## 🏗️ 5 步流水线

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1. 需求接收 │ →  │ 2. AI 解析 │ →  │ 3. 团队设计 │ →  │ 4. 远程部署 │ →  │ 5. 实时监控 │
│ 📄 💬 📋  │    │ 🧠        │    │ 👥        │    │ ☁️        │    │ 📊        │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
   3 种方式      多模型协同      拖拽画布       4 目标           阶段/日志/指标
```

### Step 1: 需求接收 (`/builder/requirements`)
- **上传文档**: 拖拽或选择 PDF/Word/MD/TXT, 实时解析预览
- **AI 对话**: 多轮澄清, 快速问模板, 上下文记忆
- **模板库**: 6 个行业方案 (教育/电商/代码/金融/医疗/自定义)

### Step 2: AI 解析 (`/builder/analysis`)
- 动画解析 (脑波脉冲 + 进度条)
- 7 阶段: 引擎初始化 → 分词 → 项目类型 → 场景 → 合规 → 智能体 → 流程
- 提取: 项目类型 / 业务场景 / 核心功能 / 预期规模 / 合规要求 / 集成需求
- 推荐: 智能体角色 (含 emoji + 颜色 + 工具 + 模型)
- 工作流: 6 步协作流程可视化

### Step 3: 团队设计 (`/builder/designer`)
- 左: 智能体库 (6 个角色, 可搜索)
- 中: 拖拽画布 (点状网格 + SVG 连线 + 缩放)
- 右: 属性面板 (名称/角色/模型/工具/提示词/连接)
- 支持: 拖拽添加 / 拖动定位 / 自动布局 / 删除节点

### Step 4: 远程部署 (`/builder/deploy`)
- **目标选择**: 4 卡片 (本地 Docker / K8s / 云厂商 / 边缘设备)
- **集群配置**:
  - K8s: Kubeconfig / 命名空间 / 集群 / 镜像仓库
  - Docker: Socket / 网络模式 / 数据卷
  - 云厂商: 阿里云 ACK / 腾讯云 TKE / AWS EKS / Azure AKS
  - 边缘: 设备列表 / SSH 用户 / 认证方式
- **资源配置**: 副本数 / CPU / 内存 / 自动伸缩范围
- **成本估算**: 实时计算 ¥X / 月

### Step 5: 实时监控 (`/builder/monitor`)
- **顶部状态卡**: 部署状态 / 完成阶段 / 已耗时 / 运行智能体
- **8 阶段时间线**: 代码校验 → 构建镜像 → 推送 → 命名空间 → 配置 → Pod → 健康检查 → 流量
- **实时日志**: 深色终端样式, INFO/WARN/ERROR 着色
- **容器状态**: 圆点呼吸动画 (running/starting/failed), CPU/MEM 实时
- **QPS 折线**: SVG 平滑曲线, 当前/峰值/平均
- **告警面板**: 实时告警列表

### Step 6: 发布管理 (`/builder/releases`)
- **版本时间线**: v1.0.0 (current) / v0.9.0 (rollback) / v0.8.0 (failed)
- **版本详情**: 6 项元数据 (版本/作者/时间/智能体数/副本数/镜像 Tag)
- **变更说明**: Markdown 风格 + 三色变更列表 (+/−/~)
- **智能体变更可视化**: 新增/修改/删除 彩色标签
- **部署统计**: 12 总发布 / 10 成功 / 1 回滚 / 1 失败
- **操作**: 差异查看 / 一键回滚 / 下载配置

- 部署进行中: 旋转 icon (2s 无限循环)

## 🛠️ 技术栈

- **前端**: Vue 3 (Composition API) + Element Plus + 原生 SVG + CSS3
- **路由**: Vue Router 4 (嵌套子路由)
- **状态**: Composition API (ref/reactive/computed) + props/emit
- **可视化**: 原生 SVG (无需 ECharts/D3, 减少依赖)
- **动画**: CSS3 keyframes + Vue Transition
