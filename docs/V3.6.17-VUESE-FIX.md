# V3.6.17 @vueuse/core 缺 computedEager 修复

## 1. 问题

用户报错：
```
node_modules/@vueuse/core/index.mjs' does not provide an export named 'computedEager'
```

**根因**：
- `package.json` 声明 `@vueuse/core: ^7.7.0`
- 实际安装 7.7.1
- `computedEager` 在 **vueuse 8.x-9.x** 才有
- 7.x 没这个 export

## 2. 解决方案

### 2.1 升级 @vueuse/core 到 ^8.9.0

```bash
cd frontend
npm install @vueuse/core@^8.9.0
```

### 2.2 替代方案 (无需重装)

```js
// 之前
import { computedEager } from '@vueuse/core'
const x = computedEager(() => someValue.value)

// 之后 (标准 computed)
import { computed } from 'vue'
const x = computed(() => someValue.value)
```

## 3. 项目状态 (V3.6.17+)

- `src/` 中无 `computedEager` 引用
- `package.json` 升级到 `^8.9.0`
- 用户需重装依赖
