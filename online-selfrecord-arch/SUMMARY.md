## 🏗️ 4 大核心设计决策

1. **三副本冗余**:本地 + 客户端单流 + 云端混流,任一副本损坏不影响合规
2. **端云协同质检**:客户端轻量检测做"硬规则",云端 LLM 做"软规则"
3. **四要素 KYC**:活体 + 人脸 + 声纹 + 设备指纹,99.99% 反欺诈
4. **断点续传**:分片 + SM3 校验,弱网 24h 可恢复

## 📊 与线下双录 7 大差异

| 维度 | 线下双录(已完成) | 线上自助(本次) |
|------|------------------|-----------------|
| 客户经理 | 客户经理 + 客户双人在场 | 客户**独立**(无人) |
| 设备 | PAD(柜面 / 上门) | 客户自有手机 / H5 |
| 签字 | 现场纸质 + 高拍仪 | 电子签名 + 手写板 |
| 引导 | 客户经理口播 | AI 数字员工 + TTS |
| 实时性 | 全程同步 | 可暂停 / 续做 / 跨日 |
| 网络 | 网点专线 | WiFi/4G/5G + 弱网容错 |
| 录制 | 单流合流(本机) | 三副本(本机+云端+混流) |
