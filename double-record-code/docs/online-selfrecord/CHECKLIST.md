# 线上自助双录架构设计 - 验收标准

> 📋 评审 checklist · 用于团队内部评审 + 监管沟通

## ✅ 必达项(MUST)

### 合规性

- [ ] 满足《宁波保险销售行为远程同步录音录像管理暂行办法》(2024.3 实施)全部 32 条
- [ ] 满足《银保监办发[2017]110号》销售专区录音录像要求
- [ ] 满足《保险销售行为可回溯管理暂行办法》(保监发[2017]54号)
- [ ] 满足等保 2.0 三级要求
- [ ] 满足 PIPL(个人信息保护法)要求
- [ ] 100% 数据境内存储,无境外 CDN/LLM 调用
- [ ] 密码法要求:SM2/SM3/SM4 国产算法 100% 覆盖
- [ ] 视听资料保留 ≥ 10 年(保单终止起算)
- [ ] 60+ 高龄 / 投连险 100% 抽检
- [ ] 30% 抽检 + 犹豫期全检

### 业务流程

- [ ] 8 个核心节点全部覆盖
- [ ] 客户身份"四要素"核验(活体+人脸+声纹+设备)
- [ ] AI 引导员可打断 + 续做
- [ ] 电子签名采用数字证书 + 手写板 + 笔迹比对
- [ ] 关键节点客户明确肯定答复(ASR 校验)
- [ ] 风险揭示不可跳过,客户必须听完
- [ ] 签字过程全程录像 + 截图
- [ ] 结束确认后 24h 内可申诉

### 技术能力

- [ ] WebRTC 延迟 ≤ 500ms
- [ ] 40% 丢包仍可通话
- [ ] 一次性通过率 ≥ 95%
- [ ] 端到端加密(SM2 + DTLS-SRTP + SM4)
- [ ] 三副本冗余(本地+单流+混流)
- [ ] 断点续传支持 30min 中断恢复
- [ ] 离线补录支持 24h 完全断网
- [ ] 跨日续做支持 72h 内继续
- [ ] 多端覆盖:APP / 小程序 / H5 / PAD

### 性能指标

- [ ] 峰值并发 ≥ 10000 路
- [ ] API QPS ≥ 3000
- [ ] 实时质检 P95 < 800ms
- [ ] 签名验证 P95 < 200ms
- [ ] 链上存证 P95 < 2s
- [ ] 单笔完成时长 ≤ 8min(中位数)

## 🎯 推荐项(SHOULD)

### 客户体验

- [ ] 7×24h 客服兜底(首 3 个月)
- [ ] "线下转线上"过渡引导
- [ ] 多语言(普通话 + 粤语 + 英语)
- [ ] 适老化(60+ 大字体、慢语速)
- [ ] 弱网降级提示

### 风控增强

- [ ] 联邦风控(跨设备/账号关联)
- [ ] 行为分析(语速/停顿/翻页速度)
- [ ] 情绪识别(异常情绪预警)
- [ ] 同屏检测(防止代签/指导)
- [ ] 黑名单共享(银保监黑名单库)

### 智能化

- [ ] AI 引导员支持多轮对话
- [ ] 智能问答(客户随时提问)
- [ ] 自动话术适配(根据产品/客户)
- [ ] 情绪安抚(检测到焦虑时)

## 💡 可选项(COULD)

### 增值服务

- [ ] 双录视频自动剪辑(关键片段标记)
- [ ] 智能生成客户报告
- [ ] 推荐合适产品
- [ ] 语音克隆(银行官方声音)

### 生态扩展

- [ ] 接入保险协会黑名单
- [ ] 跨行双录互认(同业联盟)
- [ ] 银保监实时上报

## ❌ 禁止项(MUST NOT)

- [ ] ❌ 不得使用境外 LLM/AI 服务
- [ ] ❌ 不得使用境外 CDN/对象存储
- [ ] ❌ 不得收集与服务无关的个人信息
- [ ] ❌ 不得在未授权情况下保留客户生物特征
- [ ] ❌ 不得在客户端缓存合同/证件超过 24h
- [ ] ❌ 不得跳过风险揭示节点
- [ ] ❌ 不得代替客户做出意思表示
- [ ] ❌ 不得在客户不知情情况下录音录像
