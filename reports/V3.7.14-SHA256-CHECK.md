## 检查方法

```bash
find backend -name "*.java" | xargs grep -l "Jwts.parser\|hmacShaKeyFor\|signWith" 2>/dev/null
# 输出: 3 个文件
# - backend/minimax-auth/.../JwtTokenProvider.java
# - backend/minimax-common/.../JwtAuthenticationFilter.java
# - backend/minimax-gateway/.../JwtAuthGlobalFilter.java
```

3 个文件 1 个签发 (auth) + 2 个验证 (common + gateway), 都用 SHA-256 规整

## 14 module 实际行为

- **gateway**: 拦截所有外部 HTTP 请求, 验证 JWT, 注入 X-User-Id 等头
- **common filter**: 业务模块用, 解析 X-User-Id 或自己验证 JWT
- **业务模块 (chat/agent/...)**: 注册 JwtAuthenticationFilter, 走 common filter
