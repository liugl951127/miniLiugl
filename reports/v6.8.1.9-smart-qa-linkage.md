## 💡 关键发现

1. **智能问答是 chat 流, 不是直接 AI 调用**
   - 前端 `/sessions/{id}/messages/stream` → chat 服务
   - chat 内部经 gateway → ai (`/ai/generate`)
   - 链路 3 跳: 前端 → chat → ai

2. **SSE 协议设计合理**
   - start 事件确保流开始
   - content 事件字符级 (打字机)
   - source 事件 RAG 引用
   - done 事件包含统计 (totalChars)
   - error 事件错误处理

3. **前端兼容老 alias**
   - V3.7.25+ 统一 5 type (content/tool_call/source/done/error)
   - V3.7.3+ 老代码用 chunk/toolcall/src/finish/err
   - useBusinessStream 用 TYPE_MAP 兼容

4. **历史 bug 修复后链路才通**
   - 修了 context-path 双重 v1
   - 修了 gateway StripPrefix=2
   - 修了 3 个 controller 路径
   - 修了 useSpeechCall typo
   - 修了 watch import
