## 2. 后端 SseResult.sendCustom 业务自定义

```java
/**
 * V3.7.28+ 业务自定义 event 类型
 * 用于 agent 业务: step / thought / observation / final / planner-start / planner-plan / executor-step 等
 */
public static void sendCustom(SseEmitter emitter, String event, String type, Object data) {
  // 结构: {code:0, data:{event:"step", type:"content", content:"..."}}
  // 前端 useBusinessStream 剥 Result.data, 看 data.type 路由
  Map<String, Object> wrapped = new LinkedHashMap<>();
  wrapped.put("event", event);
  wrapped.put("type", type);
  wrapped.putAll((Map) data);
  send(emitter, event, wrapped);
}
```

**用法（agent 业务）**：
```java
SseResult.sendCustom(emitter, "step", "content", Map.of("content", "thinking..."));
SseResult.sendCustom(emitter, "thought", "content", Map.of("content", "reasoning..."));
SseResult.sendCustom(emitter, "observation", "content", Map.of("content", "result..."));
SseResult.sendCustom(emitter, "final", "content", Map.of("answer", "..."));
```

**前端 useBusinessStream**：
```js
onContent: (data) => {
  // data = {event: "step", type: "content", content: "thinking..."}
  if (data.event === 'step') console.log('Step:', data.content)
  if (data.event === 'final') finalAnswer.value = data.answer
}
```
