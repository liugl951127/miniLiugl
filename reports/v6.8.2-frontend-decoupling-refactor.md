## ✨ 重构方案 (V6.8.2)

### 1. 统一页面骨架 `<PageStandard>`

**替代**: page-header + el-watermark + tabs + toolbar (40 view × 30 行 = 1200 行)

```vue
<PageStandard title="用户管理" subtitle="..." :tabs="tabs" v-model:tab="tab">
  <template #actions>
    <el-button type="primary" @click="crud.openCreate">新建</el-button>
  </template>
  <template #toolbar>
    <SearchBar v-model="table.search.keyword" @search="table.searchBy" />
  </template>
  <CrudTable :table="table" :columns="columns" />
</PageStandard>
```

**优势**:
- ✅ watermark 自动生成 (用户+角色+时间)
- ✅ 标题/副标题/操作区标准化
- ✅ 标签页+工具栏可选
- ✅ 主题切换 (default / compact / card)

### 2. 通用 CRUD 表格 `<CrudTable>`

**替代**: el-table + el-pagination + 索引列 + 操作列 (45 view × 80 行 = 3600 行)

```vue
<CrudTable
  :table="table"
  :columns="[
    { prop: 'name', label: '名称', sortable: true },
    { prop: 'status', label: '状态', type: 'tag', tags: { active: 'success' } },
    { prop: 'createdAt', label: '创建时间', type: 'time' },
    { prop: 'actions', label: '操作', type: 'actions',
      actions: [
        { label: '编辑', icon: 'Edit', event: 'edit' },
        { label: '删除', icon: 'Delete', type: 'danger', event: 'delete' },
      ]
    }
  ]"
  @action="onAction"
>
  <template #batch-actions>
    <el-button type="danger">批量删除</el-button>
  </template>
</CrudTable>
```

**支持的列类型**:
- `index` - 自动计算页内序号
- `tag` - el-tag 自动映射 (tags: { key: 'type' })
- `time` - TimeAgo 智能相对时间
- `date` - 格式化日期
- `number` - 千分位数字
- `dict` - 字典映射
- `switch` - 开关切换
- `image` - 缩略图 + 预览
- `link` - 链接
- `custom` - 自定义插槽
- `actions` - 操作按钮组

**特性**:
- ✅ 集成 useTable 状态
- ✅ 自动加载/刷新/分页
- ✅ 选择列 + 批量操作条
- ✅ 固定列 / 排序 / 溢出提示
- ✅ 自定义列插槽

### 3. 通用表单抽屉 `<FormDrawer>`

**替代**: el-drawer + el-form + 字段手写 (30 view × 100 行 = 3000 行)

```vue
<FormDrawer
  :crud="crud"
  :fields="[
    { prop: 'name', label: '名称', required: true, component: 'input', span: 12 },
    { prop: 'email', label: '邮箱', component: 'input', rules: { type: 'email' } },
    { prop: 'type', label: '类型', component: 'select',
      options: [{ value: 1, label: '管理员' }, { value: 2, label: '用户' }] },
    { prop: 'description', label: '描述', component: 'textarea', rows: 4, span: 24 },
  ]"
/>
```

**支持的字段类型**:
- input / input-number / textarea
- select (单选/多选)
- radio-group / checkbox-group
- switch
- date / datetime / time
- cascader / slider / rate / color
- upload

**特性**:
- ✅ 自动标题 (新建/编辑/查看)
- ✅ 自动校验规则
- ✅ 集成 useCrud
- ✅ 字段配置化
- ✅ 网格布局 (span)
- ✅ 自定义插槽

### 4. 通用表格状态 `useTable()`

**替代**: 60 view × 15 行 reactive = 900 行

```js
const table = useTable({
  fetcher: async (params) => await http.get('/users', { params }),
  defaultPageSize: 20,
})

// 模板直接用
// table.data / table.loading / table.total
// table.page.current / table.page.size
// table.search.keyword
// table.hasSelection / table.selectionCount
// table.load() / table.refresh() / table.searchBy() / table.setFilter()
```

**特性**:
- ✅ 兼容多种后端返回格式 (data.list / data.records / data)
- ✅ 自动 onMounted 加载
- ✅ 搜索/筛选/排序/分页 全部联动
- ✅ 错误处理
- ✅ 选择管理

### 5. 通用 CRUD 业务 `useCrud()`

**替代**: 70 view × 30 行 CRUD 逻辑 = 2100 行

```js
const crud = useCrud({
  createApi: (data) => http.post('/users', data),
  updateApi: (id, data) => http.put(`/users/${id}`, data),
  deleteApi: (id) => http.delete(`/users/${id}`),
  refresh: () => table.refresh(),
})

// crud.openCreate() / crud.openEdit(row) / crud.openView(row)
// crud.doSubmit() / crud.doDelete(row) / crud.doBatchDelete(selection)
// crud.dialog.visible / crud.form / crud.isCreate / crud.isEdit
```

**特性**:
- ✅ 自动弹窗状态 (visible / mode / submitting)
- ✅ 自动表单数据
- ✅ 自动 confirm 弹窗 (可关闭)
- ✅ 自动 toast 成功/失败提示
- ✅ 批量删除

### 6. 通用确认弹窗 `useConfirm()`

**替代**: 70 view × 5 行 ElMessageBox.confirm = 350 行

```js
const confirm = useConfirm()
const ok = await confirm({ title: '删除?', message: '不可恢复', type: 'warning' })
if (ok) { /* do delete */ }
```

**特性**:
- ✅ 简化调用 (不 try-catch)
- ✅ 统一配置 (拖拽/不点遮罩关闭)
- ✅ 默认值

### 7. 页面统一初始化 `usePageSetup()`

**替代**: 87 view × 5 行 import + 5 行 setup = 870 行

```js
const ctx = usePageSetup({
  title: '用户管理',
  requires: ['admin'],
  setup: ({ userStore, toast }) => { /* 业务初始化 */ },
})
```

**特性**:
- ✅ 自动注入 userStore / toast / confirm / router / route
- ✅ 自动设置 document.title
- ✅ 自动鉴权 (requires 角色检查)
- ✅ 自动 onMounted / onUnmounted

### 8. 统一格式化 `utils/format.js`

**替代**: 87 view × 5 个 format 函数 = 435 行

```js
formatDate(value, 'YYYY-MM-DD')
formatTime(value, 'HH:mm:ss')
formatDateTime(value)
formatNumber(value, 2)
formatFileSize(bytes)
truncate(str, 50)
formatRelativeTime(value)
```

### 9. 全局组件注册 `main.js`

```js
// V6.8.2+ 全局注册业务组件
import * as business from '@/components'
for (const [name, comp] of Object.entries(business)) {
  app.component(name, comp)
}
```

**优势**: 87 view 不用每个 import, 直接 `<PageStandard />` `<CrudTable />` 就能用.
