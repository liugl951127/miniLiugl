# V3.7.19+ SW build time 自动注入 (替代 v3.5.92 硬编码)

## 问题

```js
// usePwa.js 之前
registration = await navigator.serviceWorker.register('/sw.js?v=3.5.92', { ... })
```

- ❌ 硬编码版本号, 浏览器缓存老 SW
- ❌ 新 SW install 后 `controller` 没变, `needRefresh` 不触发
- ❌ 跟 vite plugin 注入的 `__SW_BUILD_TIME__` 冲突

## 修复

**1. usePwa.js 动态版本号**:
```js
const buildVersion = (typeof __SW_BUILD_TIME__ !== 'undefined') 
  ? __SW_BUILD_TIME__ 
  : new Date().toISOString()
registration = await navigator.serviceWorker.register(
  `/sw.js?v=${encodeURIComponent(buildVersion)}`, 
  { scope: '/' }
)
```

**2. sw-build-time.mjs 简化** (Vite 5+ writeBundle 不可靠):
- 只保留 transformIndexHtml (HTML sw.js 引用加 ?v=ts)
- dist/sw.js 注入移到独立脚本

**3. scripts/inject-sw-build-time.mjs** (新):
- postbuild 注入 `__SW_BUILD_TIME__` 到 `dist/sw.js`
- 写 `.sw-build-time.json` 给 dev fallback

**4. package.json build 钩子**:
```json
"build": "vite build && node ../scripts/inject-sw-build-time.mjs"
```

dist/sw.js 编译结果:

```js
const SW_BUILD_TIME = '2026-08-02T04:55:24.358Z'  // ✓ 替换
```

```js
const A = typeof __SW_BUILD_TIME__ != "undefined" 
  ? __SW_BUILD_TIME__ 
  : new Date().toISOString()
i = yield navigator.serviceWorker.register(
  `/sw.js?v=${encodeURIComponent(A)}`, 
  { scope: "/" }
)
```
