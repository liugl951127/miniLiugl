# V6.8.5 /login 路由 + 全链路最终审计

## 🎯 /login 路由

✅ **直接可访问**: `http://localhost/login` (public: true)

```js
// frontend/src/router/index.js
{
  path: '/login',
  name: 'Login',
  component: () => import('@/views/auth/Login.vue'),
  meta: { public: true, title: '登录' }   // 守卫放行
}
```

### 守卫流程
1. 用户访问 `localhost/login`
2. nginx `location /` → `try_files` 命中 `index.html`
3. Vue Router 启动 → 匹配 `/login` 路由
4. `beforeEach` 守卫: `to.meta.public = true` → 放行
5. 渲染 `Login.vue`
6. 用户输入 → `userStore.login()` → 后端 `POST /api/v1/auth/login`
7. nginx `location /api/v1/auth/` → 转发到 `127.0.0.1:8081` (auth service)
8. 返回 accessToken → localStorage → `router.replace(redirect)` → 进首页

### nginx 配置 (nginx/nginx.conf)

| 路径 | 转发到 |
|---|---|
| `location = /` | `/index.html` (Vue SPA) |
| `location /` | `try_files ... /index.html` (history 模式兜底) |
| `location /api/v1/auth/` | `127.0.0.1:8081` (auth) |
| `location /api/v1/ai/` | `127.0.0.1:8094` (ai) |
| `location /api/v1/chat/` | `127.0.0.1:8082` (chat) |
| `location /api/v1/agent/` | `127.0.0.1:8088` (agent) |
| `location /api/v1/admin/` | `127.0.0.1:8090` (admin) |
| `...` | (15 个 location) |
| `location /api/` (兜底) | `127.0.0.1:7080` (gateway) |
