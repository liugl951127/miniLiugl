## 2. 4 个 module 用 SseUtil 替换 SseResult

| 文件 | 改前 | 改后 |
|------|------|------|
| AgentService.java | import SseResult, SseResult.sendBusiness | import SseUtil, SseUtil.sendBusiness |
| StreamingMusicGen.java | 同上 | 同上 |
| StreamingVideoGen.java | 同上 | 同上 |
| MessageController.java | 同上 | 同上 |

```bash
sed -i 's/import com.minimax.common.sse.SseResult;/import com.minimax.common.sse.SseUtil;/' file
sed -i 's/\bSseResult\./SseUtil./g' file
```

**一致性**：
- 4 个文件全部用 SseUtil（业务新代码风格）
- SseResult 保留（向后兼容）
- 5 个 test 文件用 SseResult（SseResultTest 测的就是 SseResult 实现）
