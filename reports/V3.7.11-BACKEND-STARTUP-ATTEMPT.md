## 3. 实际启动方案

### 3.1 CI 端到端 (V3.5.65+ backend job)

```yaml
# .github/workflows/backend-build.yml
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'
      - run: cd backend && mvn -B -T 4 clean install
      - uses: actions/upload-artifact@v4
        with:
          name: target
          path: '**/target/*.jar'
```

### 3.2 本地开发

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y openjdk-17-jdk maven

# macOS
brew install openjdk@17 maven

# 编译 + 启动
cd backend
mvn -B -T 4 clean install
java -jar minimax-gateway/target/*.jar --spring.profiles.active=dev
```

### 3.3 Docker 化 (V3.5.95+ 19 service)

```bash
# 沙箱 / CI 友好
docker compose up -d minimax-gateway minimax-auth minimax-chat
# 14 module + mariadb + redis + nacos + nginx + otel-collector + jaeger
```

## 5. /api/v1/auth/me 实际验证

**接口**:
- 路径: `GET /api/v1/auth/me`
- 后端: `minimax-auth` (端口 9001)
- 前端: `authApi.me()` (V3.7.10+ 加 `_silent: true`)

**沙箱前端 curl 测试**:
```bash
# 沙箱无后端, 实际 curl 会 ECONNREFUSED
$ curl http://localhost:9001/api/v1/auth/me
curl: (7) Failed to connect to localhost port 9001
```

**真实环境 (本地 / CI / Docker)**:
```bash
# 启动后端
docker compose up -d minimax-auth mariadb

# 测试
TOKEN=$(curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' | jq -r .data.accessToken)

curl -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/v1/auth/me
# {"code":0,"data":{"id":1,"username":"admin","roles":["SUPER_ADMIN"]}}
```
