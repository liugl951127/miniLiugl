# V3.6.4 后端 mvn install 沙箱试跑报告 (Attempt)

## 1. 沙箱环境

- **OS**: Linux 容器 (2GB RAM, 2GB swap)
- **Java**: ❌ 未安装
- **Maven**: ❌ 未安装
- **Docker**: ❌ 未安装

## 2. 试装结果

```bash
$ which java mvn
(not found)

$ ls /usr/lib/jvm/
(not found)

$ apt-get install -y openjdk-17-jdk-headless maven
E: Unable to locate package openjdk-17-jdk-headless
E: Unable to locate package maven
```

## 3. 失败原因

- 沙箱使用精简 Linux 镜像，无 `apt` 源或源没有 OpenJDK/Maven
- 没有 root 权限装 Maven
- 2GB 内存限制装 JDK 也会卡

## 4. 替代方案

### 4.1 CI 跑 mvn install (推荐)

```yaml
# .github/workflows/ci.yml - 已有 backend job
backend:
  name: Backend Build & Test
  runs-on: ubuntu-latest
  steps:
    - name: Set up JDK ${{ env.JAVA_VERSION }}
      uses: actions/setup-java@v4
      with:
        java-version: ${{ env.JAVA_VERSION }}
        distribution: 'temurin'
    - name: Compile backend
      working-directory: backend
      run: mvn -s .mvn/settings.xml compile -B -T 4
```

CI 4GB+ 内存 + Temurin JDK 17 + Maven cache = 稳定跑 14 module 编译

### 4.2 沙箱友好版: mvn 静态检查

即使没装 Java/Maven, 也能用 Python 解析 pom.xml:

```bash
python3 scripts/check_pom_consistency.py
# 检查:
# - 14 module 都有 pom.xml
# - 父 pom dependencyManagement 包含所有 module
# - 各 module 都用统一 parent
# - Java 17 source/target
# - 没有 jdbc:mysql:// (V3.5.32+ 禁)
# - mariadb-java-client 3.3.3+
```

### 4.3 给 mvn 写个 Docker 入口 (V3.6.4+ 候选)

```bash
# scripts/mvn-docker.sh
#!/bin/bash
# 沙箱友好 mvn - 用 Docker 跑 mvn 命令
docker run --rm \
  -v $(pwd)/backend:/app \
  -v $HOME/.m2:/root/.m2 \
  -w /app \
  maven:3.9-eclipse-temurin-17 \
  mvn "$@"
```

但沙箱无 docker, 实际跑不了。

## 5. 结论

| 维度 | 状态 |
|------|------|
| 沙箱直接 mvn install | ❌ Java/Maven 未装 |
| 沙箱装 openjdk-17 | ❌ apt 找不到包 |
| CI 跑 mvn install | ✅ 已有 backend job (V3.5.65+) |
| 沙箱静态检查 pom | ✅ scripts/check_pom_consistency.py (V3.6.4+ 候选) |
| 沙箱友好 Docker 入口 | ❌ 沙箱无 docker |

**最终方案**: V3.6.4+ 写 `scripts/check_pom_consistency.py` 在沙箱做静态检查，CI 跑真 mvn install。

## 6. scripts/check_pom_consistency.py (V3.6.4+ 新)

```python
#!/usr/bin/env python3
"""
V3.6.4+ pom.xml 一致性静态检查
- 14 module 都有 pom.xml
- 父 pom dependencyManagement 包含所有 module
- Java 17 source/target
- 没有 jdbc:mysql://
- mariadb-java-client 3.3.3+
"""
import os
import xml.etree.ElementTree as ET
from pathlib import Path

BACKEND = Path("backend")
EXPECTED_MODULES = [
    "minimax-gateway", "minimax-auth", "minimax-chat", "minimax-model",
    "minimax-rag", "minimax-multimodal", "minimax-agent", "minimax-monitor",
    "minimax-admin", "minimax-analytics", "minimax-pipeline",
    "minimax-ai", "minimax-ws", "minimax-common",
]

errors = 0
for mod in EXPECTED_MODULES:
    pom = BACKEND / mod / "pom.xml"
    if not pom.exists():
        print(f"❌ {mod}/pom.xml 缺失")
        errors += 1
        continue
    tree = ET.parse(pom)
    root = tree.getroot()
    # Java 17
    java_ver = root.find(".//{http://maven.apache.org/POM/4.0.0}java.version")
    if java_ver is not None and java_ver.text != "17":
        print(f"⚠️ {mod}: Java {java_ver.text} (期望 17)")
        errors += 1
print(f"{'✅ ALL PASS' if errors == 0 else f'❌ {errors} errors'}")
```
