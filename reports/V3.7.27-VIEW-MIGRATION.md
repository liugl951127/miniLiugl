# V3.7.27+ view 迁移 + 后端 Music/Video 用 SseResult

## 1. chat/Index.vue 迁移

**改前**（V3.7.26-，用 session.js 中转 sendMessageStream）：
```js
import { sendMessageStream } from '@/api/session'
await sendMessageStream(sessionId, body, { streamId, signal, onChunk, onToolCall, onSource, onDone, onError })
```

**改后**（V3.7.27+，直接 useBusinessStream）：
```js
import { useBusinessStream } from '@/composables/useBusinessStream'
const stream = useBusinessStream()
await stream.send(`/sessions/${sessionId}/messages/stream`, { role, content, modelCode, images, streamId }, {
  signal: streamAbortController?.signal,
  onContent: (chunk) => { ... },  // onChunk 改 onContent
  onToolCall, onSource, onDone, onError,
})
```

✅ 省一层中转 + 拿到 `isStreaming/isPaused/progress` 直接状态

## 2. agent/Stream.vue + Multi.vue 迁移

**改前**（手写 SSE 解析 ~80 行）：
```js
const resp = await fetch('/api/v1/agent/run-stream', { ... })
const reader = resp.body.getReader()
// ... 50 行 buffer/curEvent 解析
```

**改后**（V3.7.27+）：
```js
const stream = useBusinessStream()
await stream.send('/api/v1/agent/run-stream', body, {
  signal: esController.signal,
  onContent: (data) => {
    if (data && 'event' in data) events.value.push(data)
    if (data.event === 'final') finalAnswer.value = data.data?.answer
  },
  onDone: () => { ... },
  onError: (err) => toast.error(...),
})
```

✅ 2 个 view 都用 useBusinessStream，agent stream 业务（start/step/thought/tool_call/observation/final/done）走 onContent 统一收

## 3. 后端 Music/Video Stream 用 SseResult

`backend/minimax-ai/.../StreamingMusicGen.java`:
```java
import com.minimax.common.sse.SseResult;

// 之前: 散落 try-catch + emitter.send(SseEmitter.event().name("error").data(...))
// V3.7.27+:
SseResult.sendError(emitter, e.getMessage());
SseResult.completeWithError(emitter, e);
```

`backend/minimax-ai/.../StreamingVideoGen.java` 同样改。
