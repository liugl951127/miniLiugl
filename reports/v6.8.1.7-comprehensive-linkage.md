## 修复的真错 (本次)

### 1. 后端 controller 路径缺 v1
```diff
- @RequestMapping("/ai")
+ @RequestMapping("/api/v1/ai")    // MissingAiController
- @RequestMapping("/api/ai")
+ @RequestMapping("/api/v1/ai")    // IntroController  
- @RequestMapping("/api/ai/seed")
+ @RequestMapping("/api/v1/ai/seed")  // SeedInfoController
```

### 2. 模板里 .value 误用
```diff

+ <div v-if="speechCall.interimText">    // chat/Index.vue
```

模板自动解包 ref, 不需要 .value
