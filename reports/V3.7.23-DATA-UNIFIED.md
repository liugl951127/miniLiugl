# V3.7.23+ Result.data 全面统一 (view/SSE/错误)

## V3.7.23 改动

### 1. 100+ view 扫一遍 res.data.data.data 嵌套

**找到 5 处需要改**：

| 文件 | 行 | 改前 | 改后 |
|------|----|------|------|
| views/ai/AiToolAdmin.vue | 224 | `res.data.data \|\| res.data` | `res.data` |

**V3.7.22 之后改**（统一 1 行）：`res.data` 直接是业务数据，不用剥。

### 2. http.js 错误处理加 __result 字段

```js
// V3.7.22
err.result = data

// V3.7.23 (跟成功路径统一字段名)
err.__result = data
```

业务代码现在能统一用 `err.__result`：
```js
try {
  await authApi.login(...)
} catch (e) {
  console.log('错误码:', e.__result?.code)
  console.log('错误消息:', e.__result?.message)
}
```

### 3. SSE 流式响应支持 Result 包装

`useSSEStream.js` 自动剥：

```js
let json = JSON.parse(data)
// V3.7.23+ 自动剥 Result.data
if (json && typeof json === 'object' && 'code' in json && 'data' in json && json.code === 0) {
  json = json.data
}
// 处理 chunk (json 现在是裸业务数据)
if (json.content) { ... }

// 业务错误处理 (code !== 0)
if (json && typeof json === 'object' && 'code' in json && json.code !== 0) {
  error.value = new Error(json.message || 'SSE 业务错误')
  error.value.__result = json
  isStreaming.value = false
}
```

## 兼容性

| 场景 | V3.7.23 行为 |
|------|--------------|
| 后端发 `data: {"content": "..."}` (裸) | ✅ json.content 直接处理 |
| 后端发 `data: {"code":0,"data":{"content":"..."}}` (Result) | ✅ 自动剥 data |
| 后端发 `data: {"code":1,"message":"err"}` (业务错) | ✅ 设 error.value |
| 后端发 `data: [DONE]` | ✅ 结束流 |
