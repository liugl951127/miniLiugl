# V3.7.20 SW 版本号注入修复 (Vite plugin transformIndexHtml 失效)

## 问题

**`vite-plugins/sw-build-time.mjs` 的 transformIndexHtml hook 也不跑**（Vite 5+ 行为变化）：
- dist/index.html 仍然硬编码 `?v=3.5.79`
- 用户即使更新 dist/index.html, 浏览器还是用老 SW (`controller` 不变)
- `needRefresh` 永远不触发

## 根因

`sw.js` 注册在 `frontend/index.html` 的**内联 script**（不是 `src="/sw.js"`）：
```html
<script>
  navigator.serviceWorker.register('/sw.js?v=3.5.79', { scope: '/' })
</script>
```

`transformIndexHtml` 只改 `src="/sw.js"`，改不到内联 JS。

## V3.7.20 修复

**1. 源文件改占位符**：
```html
<!-- frontend/index.html (源) -->
navigator.serviceWorker.register('/sw.js?v=__SW_BUILD_TIME__', { scope: '/' })
```

**2. postbuild 注入**（`scripts/inject-sw-build-time.mjs`）：
```js
const FILES = [
  { path: 'frontend/dist/sw.js', label: 'dist/sw.js' },
  { path: 'frontend/dist/index.html', label: 'dist/index.html' },
  // V3.7.20+ 不再修改源文件 (保持 __SW_BUILD_TIME__ 占位符)
]
for (const { path, label } of FILES) {
  let updated = content.replace(/__SW_BUILD_TIME__/g, ts)
  // 同时清理旧硬编码 ?v=3.5.79
  updated = updated.replace(/\?v=3\.5\.\d+/g, `?v=${encodeURIComponent(ts)}`)
  writeFileSync(path, updated)
}
```

**3. Vite plugin 改为 noop**：
```js
// vite-plugins/sw-build-time.mjs (V3.7.20+ 弃用)
// 之前 transformIndexHtml 改 src="/sw.js" 改不到内联 script
// 现在所有注入统一在 scripts/inject-sw-build-time.mjs (postbuild)
export default function swBuildTime() {
  return { name: 'sw-build-time-noop' }
}
```
