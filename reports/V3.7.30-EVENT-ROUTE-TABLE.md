# V3.7.30+ EVENT_TO_TYPE 通用路由表移到 SseResult

## 重构前（V3.7.29）

AgentService 自己定义路由表：
```java
private static final Map<String, String> EVENT_TO_TYPE;
static {
  EVENT_TO_TYPE.put("start", "content");
  EVENT_TO_TYPE.put("tools", "source");
  EVENT_TO_TYPE.put("thought", "content");
  EVENT_TO_TYPE.put("tool-call", "tool_call");
  EVENT_TO_TYPE.put("observation", "content");
  EVENT_TO_TYPE.put("step-error", "error");
  EVENT_TO_TYPE.put("final", "content");
  // 只有 8 个 - 业务不全
}
```

## 重构后（V3.7.30+）

路由表统一在 SseResult，**所有业务都可用**：
```java
public static final Map<String, String> EVENT_TO_TYPE = new HashMap<>();
static {
  // content 类型 (默认)
  EVENT_TO_TYPE.put("start", "content");
  EVENT_TO_TYPE.put("step-start", "content");
  EVENT_TO_TYPE.put("thought", "content");
  EVENT_TO_TYPE.put("observation", "content");
  EVENT_TO_TYPE.put("final", "content");
  EVENT_TO_TYPE.put("planner-start", "content");
  EVENT_TO_TYPE.put("planner-plan", "content");
  EVENT_TO_TYPE.put("executor-step", "content");
  EVENT_TO_TYPE.put("executor-result", "content");
  EVENT_TO_TYPE.put("heartbeat", "content");
  EVENT_TO_TYPE.put("chunk", "content");
  
  // tool_call 类型
  EVENT_TO_TYPE.put("tool-call", "tool_call");
  EVENT_TO_TYPE.put("toolcall", "tool_call");
  
  // source 类型
  EVENT_TO_TYPE.put("tools", "source");
  EVENT_TO_TYPE.put("src", "source");
  
  // error 类型
  EVENT_TO_TYPE.put("error", "error");
  EVENT_TO_TYPE.put("step-error", "error");
  EVENT_TO_TYPE.put("err", "error");
}
```

**16 个 event 路由**（含 3 个兼容老别名 chunk/toolcall/src/err）

## SseResult.sendBusiness 新 API（V3.7.30+）

```java
/**
 * V3.7.30+ 业务自定义 event 入口 (自动路由 type)
 * 业务不用关心 type, 只传 event + data
 */
public static void sendBusiness(SseEmitter emitter, String event, Object data) {
  String type = getType(event);  // 查 EVENT_TO_TYPE
  sendCustom(emitter, event, type, data);
}
```

**AgentService 简化**：
```java
// 之前 8 行路由表 + sendEvent 调 sendCustom
// 现在 0 路由表 + sendEvent 调 sendBusiness
private void sendEvent(SseEmitter emitter, String event, Object data) {
  if ("error".equals(event) || "step-error".equals(event)) {
    SseResult.sendError(emitter, msg);
  } else if ("done".equals(event)) {
    SseResult.sendDone(emitter);
  } else {
    SseResult.sendBusiness(emitter, event, data);  // 自动查 type
  }
}
```
