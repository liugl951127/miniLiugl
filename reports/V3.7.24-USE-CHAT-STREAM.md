# V3.7.24+ useChatStream Result 包装 + __result 统一字段

## 1. useChatStream 加 Result 包装支持

`useChatStream.js`（chat/Index.vue 用的）现在兼容 3 种 SSE 格式：

| 后端发 | 行为 |
|--------|------|
| `data: {"type":"content","content":"..."}` (裸) | ✅ 直接处理 |
| `data: {"code":0,"data":{"type":"content","content":"..."}}` (Result 包装) | ✅ 自动剥 data |
| `data: {"code":1,"message":"err"}` (业务错) | ✅ onError + __result 标记 |

## 2. http.js __result 字段统一

**成功路径** (V3.7.24+)：
```js
if (data && typeof data === 'object') {
  data.__result = original  // 业务用 data.__result 访问原 Result
}
return data
```

**失败路径** (V3.7.24+)：
```js
err.__result = data  // 业务用 e.__result 访问原 Result
return Promise.reject(err)
```

**业务代码现在统一用 `__result`**：

```js
// 成功
const { accessToken } = res.data || {}
console.log('请求时间戳:', res.data?.__result?.timestamp)

// 失败
try {
  await authApi.login(...)
} catch (e) {
  console.log('错误码:', e.__result?.code)
  console.log('错误消息:', e.__result?.message)
  console.log('时间戳:', e.__result?.timestamp)
}
```

## 3 个统一字段访问

| 字段 | 成功 | 失败 |
|------|------|------|
| `code` | `0` | 非 0 |
| `message` | `"success"` | 错误消息 |
| `__result` | 业务对象 | 错误对象 |

`__result` 同时给到 HTTP 响应、SSE chunk 错误。
