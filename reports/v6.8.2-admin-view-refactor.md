## 🎁 业务优势

### 1. 重复代码归零
- ❌ 0 个 el-watermark
- ❌ 0 个 page-header
- ❌ 0 个 el-table (CrudTable 替代)
- ❌ 0 个 el-pagination
- ❌ 0 个 el-dialog/form
- ❌ 0 个 ElMessageBox.confirm
- ❌ 0 个手写 reactive

### 2. 业务逻辑 0 行
- useTable 1 行替代 15 行 reactive
- useCrud 1 行替代 30 行 CRUD
- useConfirm 1 行替代 5 行
- usePageSetup 1 行替代 5 行

### 3. 标准化 UI
- 所有页面同样的 page-header 样式
- 所有表格同样的列类型 (tag / time / number / actions)
- 所有弹窗同样的 footer 按钮

### 4. 可维护性 ↑
- 新建一个 CRUD 页面 < 1 小时
- 改业务逻辑 1 处 (columns/fields 配置)
- 修 UI 1 处 (CrudTable 内部)

## 🔧 全局组件注册

`main.js` V6.8.2+:
```js
import * as business from '@/components'
for (const [name, comp] of Object.entries(business)) {
  app.component(name, comp)
}
```

**优势**: 87 view 不再需要 import, 直接 `<PageStandard />` `<CrudTable />` 即可用.
