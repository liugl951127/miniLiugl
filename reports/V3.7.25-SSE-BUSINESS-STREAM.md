# V3.7.25+ useBusinessStream 统一 5 type + 全栈 SSE Result 包装

## 1. useBusinessStream 抽离统一

`frontend/src/composables/useBusinessStream.js` 5 type 统一：

| type | 别名 (兼容老) | 字段 |
|------|--------------|------|
| content | chunk | content |
| tool_call | toolcall | toolCall |
| source | src | source |
| done | finish | - |
| error | err | message / __result |

```js
const TYPE_MAP = {
  content: 'content',
  tool_call: 'tool_call',
  source: 'source',
  done: 'done',
  error: 'error',
  // 兼容老代码 (V3.7.3+ useChatStream 用 'chunk')
  chunk: 'content',
  toolcall: 'tool_call',
  src: 'source',
  finish: 'done',
  err: 'error',
}
```

## 2. 全栈 SSE 入口加 Result 兼容

### 前端

**`session.js` sendMessageStream**（chat 用）：
```js
let obj = JSON.parse(data)
// V3.7.25+ Result 包装自动剥
if (obj && 'code' in obj && 'data' in obj && obj.code === 0) {
  obj = obj.data
}
// 业务错误
if (obj && 'code' in obj && obj.code !== 0) {
  const err = new Error(obj.message)
  err.__result = obj
  onError && onError(err)
  return
}
```

**`useChatStream.js`**（chat/Index.vue 用的）：V3.7.24+ 已加

**`useBusinessStream.js`**（统一）：V3.7.25+ 新增, chat/agent/rag 都用

### 后端

**`AgentService.sendEvent`**：error/done 事件自动包 Result：

if ("error".equals(event) || "done".equals(event)) {
  int code = "error".equals(event) ? 1 : 0;
  String msg = ...;

## 3. 5 type 业务使用

```js
// chat/agent/rag 统一
const { messages, toolCalls, sources, send } = useBusinessStream()

await send('/api/chat/stream', payload, {
  onContent: (c) => console.log('chunk:', c),
  onToolCall: (tc) => console.log('tool:', tc),
  onSource: (s) => console.log('source:', s),
  onDone: () => console.log('done'),
  onError: (e) => console.log('error:', e.message, e.__result),
})
```
