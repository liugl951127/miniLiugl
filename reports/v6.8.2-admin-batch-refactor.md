## 💡 关键设计

### 1. 4-tab 复杂页面 (Alerts)
- 拆 4 个 `useTable()`, 互不干扰
- `onTabChange` 切换时按需加载
- 状态独立: 切 tab 不重置其他 tab

### 2. 完整 CRUD (Provider)
- 1 个 `useTable` + 1 个 `useCrud` + 1 个 `FormDrawer`
- columns 数组配置 8 列
- formFields 数组配置 8 字段
- 业务逻辑 0 行手写

### 3. 实时监控 (Metrics / Cluster)
- `v-model:autoRefresh` + `setInterval` 5s
- `onUnmounted` 清理 timer
- `useTable` + ECharts 图表组合

### 4. 跨应用管理 (WechatUnionidAdmin)
- 3 tab: 列表 / 合并 / 详情
- 合并表单 2 个 user 字段
- confirm 弹窗不可逆操作警告
