# V3.7.21+ 登录流程 Result 包装剥 data 修复

## 问题

**后端 `AuthController.login` 返 `Result<LoginResponse>`**：
```java
@PostMapping("/login")
public Result<LoginResponse> login(@Valid @RequestBody LoginRequest req, HttpServletRequest http) {
    return Result.ok(authService.login(req, http));
}
```

**前端 `userStore.login` 之前错误解构**（V3.7.21 前）：
```js
async function login(payload) {
  const res = await authApi.login(payload)
  const { accessToken: at, refreshToken: rt, user } = res.data  // ❌ res.data 是 Result 包装
  accessToken.value = at      // undefined
  refreshToken.value = rt     // undefined
  profile.value = user        // undefined
  return res
}
```

**实际响应结构**：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "eyJhbGc...",
    "refreshToken": "eyJhbGc...",
    "expiresIn": 1800,
    "tokenType": "Bearer",
    "user": { "id": 1, "username": "admin", ... }
  },
  "timestamp": 1722566400000
}
```

**前端解构 `res.data`**（即 Result 顶层）→ 拿到 `code/message/data/timestamp`，没有 `accessToken/refreshToken/user` → **全 undefined**

## 后果

1. `accessToken.value = undefined` → 后续请求不带 `Authorization` 头
2. `profile.value = undefined` → 渲染 layout 时 `profile.value?.roles` 失败
3. `/api/v1/auth/me` 401 (没 token) → layout catch 兜底
4. 提示"登录成功"但实际 token 是空

## V3.7.21 修复

**userStore 3 个方法**全部改用 `res.data.data || res.data || {}` 兜底：

```js
// 1. login
const { accessToken: at, refreshToken: rt, user } = res.data.data || res.data || {}
accessToken.value = at || ''
refreshToken.value = rt || ''
profile.value = user || null

// 2. fetchProfile
profile.value = res.data.data || res.data

// 3. refreshAccessToken
const data = res.data.data || res.data || {}
accessToken.value = data.accessToken || ''
refreshToken.value = data.refreshToken || ''
return data.accessToken
```

**3 层 fallback 兼容**：
- `res.data.data` — 标准 Result 包装 (后端真实响应)
- `res.data` — 已经剥过 (兼容老的 mock 或 http.js 改动)
- `{}` — 都没, 全部 undefined 也安全

## 防御性收益

✅ 字段缺失不崩（`at || ''` 而不是 `at`）
✅ 后端改结构兼容（双层 `res.data.data || res.data`）
✅ 401 后 profile=null 不会渲染错（`profile.value = user || null`）
