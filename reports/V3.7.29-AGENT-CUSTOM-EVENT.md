# V3.7.29+ AgentService 业务自定义 event 统一调用

## 改前（V3.7.26-）

```java
private void sendEvent(SseEmitter emitter, String event, Object data) {
  if ("error".equals(event)) { ... } 
  else if ("done".equals(event)) { ... }
  else { SseResult.send(emitter, event, data); }  // 业务 event 也走标准 send
}
```

业务 event (start/tools/step-start/thought/tool-call/observation/final) 跟标准 5 type 走一样的 `SseResult.send`，**没有 type 路由**，前端 useBusinessStream 收不到 onToolCall/onSource 等细粒度回调。

## 改后（V3.7.29+）

```java
private static final Map<String, String> EVENT_TO_TYPE;
static {
  EVENT_TO_TYPE = new HashMap<>();
  EVENT_TO_TYPE.put("start", "content");
  EVENT_TO_TYPE.put("tools", "source");
  EVENT_TO_TYPE.put("step-start", "content");
  EVENT_TO_TYPE.put("thought", "content");
  EVENT_TO_TYPE.put("tool-call", "tool_call");
  EVENT_TO_TYPE.put("observation", "content");
  EVENT_TO_TYPE.put("step-error", "error");
  EVENT_TO_TYPE.put("final", "content");
}

private void sendEvent(SseEmitter emitter, String event, Object data) {
  if ("error".equals(event) || "step-error".equals(event)) {
    SseResult.sendError(emitter, msg);
  } else if ("done".equals(event)) {
    SseResult.sendDone(emitter);
  } else {
    // 业务自定义 event: 走 sendCustom 包装 event+type
    String type = EVENT_TO_TYPE.getOrDefault(event, "content");
    SseResult.sendCustom(emitter, event, type, data);
  }
}
```

## 路由表 (event → 5 type)

| event | type | 前端回调 |
|-------|------|---------|
| start | content | onContent |
| tools | source | onSource |
| step-start | content | onContent |
| thought | content | onContent |
| tool-call | tool_call | onToolCall |
| observation | content | onContent |
| step-error | error | onError |
| final | content | onContent |
| done | (走 sendDone) | onDone |
| error | (走 sendError) | onError |
| 未知 | content (默认) | onContent |

## 完整链路

```
[后端 AgentService.runStream]
  ↓ sendEvent(emitter, "tool-call", {name, args, ...})
[SseResult.sendCustom(emitter, "tool-call", "tool_call", data)]
  ↓ wrapped = {event: "tool-call", type: "tool_call", name, args, ...}
[SseResult.send 包装 Result]
  ↓ emitter 发送 {code:0, data:{event, type, name, args}, timestamp}
[SSE 协议]
[前端 useBusinessStream 剥 Result.data]
  ↓ data.type = "tool_call" → onToolCall
[前端拿 data 业务字段]
```

## 前端 useBusinessStream 验证

```js
onContent: (data) => { /* data.type === 'content' 业务: start/thought/observation/final */ },
onToolCall: (data) => { /* data.type === 'tool_call' 业务: tool-call */ },
onSource: (data) => { /* data.type === 'source' 业务: tools */ },
onDone: () => { /* done event */ },
onError: (err) => { /* error / step-error event, err.__result 包含 data */ },
```
