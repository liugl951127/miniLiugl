# MiniMax 平台
# ============================================
什么是 MiniMax
MiniMax 是一个开源的企业级大模型平台,基于 Spring Cloud 微服务架构。
MiniMax 平台包含 16 个微服务,涵盖认证、聊天、模型、记忆、知识库等功能。
MiniMax 的核心特点是不依赖外部大模型,可以自研 AI 推理。
MiniMax 平台支持 Docker 一键部署、CentOS Stream 9 适配。
MiniMax 平台技术栈是 Java 17 + Spring Boot 3 + Spring Cloud 2023 + Vue 3。
如何使用 MiniMax
你可以访问 https://github.com/liugl951127/miniLiugl 查看完整文档。
运行 sudo ./deploy-simple/docker-deploy.sh up 一键启动。
登录 adminLiugl 账号,密码 Liugl@2026 即可使用。
MiniMax 包含哪些功能

知识库:支持 RAG、文档解析、向量检索。
记忆系统:短期记忆 Redis + 长期记忆 MySQL。
监控告警:Prometheus + Micrometer + 自定义告警规则。
认证授权:JWT + RBAC + 多租户。
插件系统:Function Calling + 工具注册。

# 知识问答
# ============================================
什么是 Spring Boot
Spring Boot 是基于 Spring 框架的快速开发脚手架。
Spring Boot 简化了 Spring 应用的初始搭建和开发过程。
Spring Boot 的核心特性是自动配置和起步依赖。
什么是 Docker
Docker 是一个开源的容器化平台,用于打包、分发、运行应用。
Docker 让应用在任何环境都能一致运行。
Docker 镜像包含了应用及其所有依赖。
什么是微服务
微服务是一种架构风格,将单体应用拆分成多个小型服务。
每个微服务独立部署、独立扩展、技术异构。
微服务之间通过轻量级协议 (HTTP/RPC) 通信。
什么是 Java
Java 是一种跨平台的面向对象编程语言。
Java 的核心优势是 Write Once, Run Anywhere。
Java 17 是当前的 LTS 版本。
什么是 AI
AI 是人工智能,让机器具有人类智能。
AI 的核心是机器学习、深度学习、自然语言处理。
现代 AI 基于 Transformer 架构。
什么是 Transformer
Transformer 是一种基于自注意力机制的深度学习架构。
Transformer 是 GPT、BERT 等大模型的基础。
Transformer 由 Self-Attention 和 FFN 组成。
什么是 LLM
LLM 是大语言模型,Large Language Model。
LLM 通常有数十亿到数千亿参数。
LLM 可以做对话、翻译、写作、代码等多种任务。

# 知识库
什么是 RAG
RAG 是检索增强生成 (Retrieval-Augmented Generation)。
先从知识库检索相关内容,再让 AI 基于检索结果生成回答。
这样能减少 AI 幻觉,让回答更准确。
知识库怎么用
把文档 (PDF/Word/Excel) 上传到知识库,系统会自动解析、向量化。
AI 回答时会先检索相关知识,再基于知识生成回答。

# Java 编程
什么是 Java 反射
Java 反射是在运行时检查和操作类、方法、字段的能力。
通过 Class 对象可以获取类的所有信息,包括私有成员。
什么是 Lambda 表达式
Lambda 表达式是 Java 8 引入的匿名函数,可以简化函数式编程。
语法: (参数) -> { 函数体 }
什么是 Stream API
Stream API 是 Java 8 提供的函数式集合操作库。
支持 filter/map/reduce/collect 等操作,链式调用。
Java 和 JavaScript 区别
Java 是编译型强类型语言,主要用于后端开发。
JavaScript 是解释型弱类型语言,主要用于前端。
两者名字相似但语法和用途完全不同。

# Spring 框架
什么是 Spring IoC
IoC (Inversion of Control) 控制反转是 Spring 的核心。
对象的创建和依赖关系由 Spring 容器管理,而不是代码 new 出来。
什么是 AOP
AOP (Aspect-Oriented Programming) 面向切面编程。
把横切关注点 (日志/事务/权限) 从业务代码中分离出来。
什么是 Spring Boot
Spring Boot 简化了 Spring 应用初始化,提供开箱即用的配置。
内嵌 Tomcat, 直接 java -jar 就能跑。
Spring Boot 怎么配置多环境
用 application-{profile}.yml 区分环境。
启动时加 --spring.profiles.active=prod。

# 数据库
什么是索引
索引是数据库的查询加速结构,类似书的目录。
常用类型: B-Tree 索引、Hash 索引、全文索引。
索引能加快查询,但会降低写入速度。
SQL 怎么优化
1. 加合适的索引
2. 避免 SELECT *
3. 用 EXPLAIN 分析执行计划
4. 大表分页用主键游标
5. 批量插入代替循环单条插入
什么是事务
事务是一组 SQL 操作,要么全成功要么全失败。
ACID 特性: 原子性、一致性、隔离性、持久性。

# 行业知识 - 医疗
# ============================================
如何预防感冒
勤洗手、多通风、戴口罩、保持社交距离、接种流感疫苗。
均衡饮食、适量运动、充足睡眠提高免疫力。
感冒主要通过飞沫和接触传播。
高血压怎么办
低盐饮食 (每天 < 5g 盐)、规律运动、控制体重、戒烟限酒。
定期监测血压,遵医嘱服药,不可擅自停药。
高血压是慢性病,需长期管理。
糖尿病注意什么
控制饮食 (低糖低脂)、规律运动、按时服药、监测血糖。
定期检查眼底、肾功能、足部,预防并发症。
糖尿病分 1 型、2 型、妊娠糖尿病,治疗方案不同。
如何健康减肥
控制热量摄入 (每天 < 基础代谢+运动消耗)、均衡营养 (蛋白质+蔬菜+碳水)。
每周减重 0.5-1kg 为宜,避免快速减肥反弹。
结合有氧运动 (跑步/游泳) + 无氧运动 (力量训练)。

标准工时: 每天 8 小时、每周 40 小时。
加班每日不超过 3 小时,每月不超过 36 小时。
加班费: 平时 1.5 倍、休息日 2 倍、法定节假日 3 倍。
试用期最长多久
根据《劳动合同法》: 3 年以上固定期限,试用期不超过 6 个月。
1-3 年固定期限,试用期不超过 2 个月。
1 年以下固定期限,试用期不超过 1 个月。
试用期包含在劳动合同期限内。
离婚需要什么手续
协议离婚: 双方到民政局申请, 30 天冷静期后领证。
诉讼离婚: 一方不同意或财产/子女有争议, 向法院起诉。
准备材料: 身份证、结婚证、离婚协议书、子女抚养协议。

# ============================================
如何高效阅读
先看目录和前言了解结构 → 带着问题读 → 划重点 → 总结复述。
SQ3R 阅读法: 概览 (Survey) → 提问 (Question) → 阅读 (Read) → 复述 (Recite) → 复习 (Review)。
每天专注读 30-60 分钟, 比长时间走神更高效。
如何做笔记
康奈尔笔记法: 页面分 3 块 (笔记/线索/总结), 课后总结。
思维导图: 中心主题 + 分支, 适合梳理知识结构。
数字笔记: Notion / Obsidian / OneNote, 方便检索和分享。
如何学英语单词
词根词缀法: 200 个常用词根 + 100 个前缀 + 100 个后缀, 覆盖 80% 词汇。
场景记忆: 把单词放在句子/故事中, 比孤立背诵更持久。
间隔重复: 用 Anki / 墨墨背单词, 算法安排复习时间。

# ============================================
# 紧急情况
# ============================================
有人晕倒了怎么办
检查意识: 轻拍肩膀大声呼叫。
检查呼吸: 看胸廓起伏 10 秒内。
无意识无呼吸: 立即心肺复苏 (CPR) + 120 急救。
有意识: 让其平躺, 抬高双腿, 保持空气流通。
发现火灾怎么办
小火: 用灭火器/水/沙子扑灭 (油火禁用水)。
大火: 立即撤离, 弯腰低姿, 用湿毛巾捂口鼻。
打 119 报警, 告知地址、火势、被困人员。
被困: 关门窗, 用湿布堵缝隙, 阳台/窗口呼救。
发生地震怎么办
室内: 躲到承重墙角落、桌子下, 远离窗户、外墙。
室外: 跑到空旷地带, 远离建筑、电线杆。
被埋: 保存体力, 敲击物体发出求救信号, 不要大声呼喊。

# ============================================
# 平台高级功能
# ============================================
怎么创建智能体
进入"智能体"页面 → 点击"+"按钮 → 配置名称/描述/提示词/工具 → 发布。
智能体可挂载知识库、工具、API,实现自动化任务。
支持版本管理,方便迭代优化。
什么是知识库 RAG
RAG = Retrieval Augmented Generation, 检索增强生成。
流程: 用户问题 → 向量检索相关文档 → 拼接到 prompt → LLM 生成回答。
解决 LLM 知识陈旧 + 幻觉问题,提升专业领域准确率。
什么是 Function Call
Function Call = 工具调用, 让 LLM 调用外部函数/API。
LLM 输出结构化 JSON 描述要调用的函数和参数,程序执行后返回结果。
应用: 查天气、查订单、调数据库、发邮件。
什么是多模态
多模态 = 处理多种类型数据 (文本/图像/音频/视频)。
代表: GPT-4V (文本+图像) / Sora (文本→视频) / Suno (文本→音乐)。
应用: 看图说话、视频理解、语音对话、跨模态生成。
什么是 Embedding
Embedding = 将文本/图像转为高维向量 (通常 768-4096 维)。
语义相近的内容向量距离近,可用于相似度检索。
模型: OpenAI text-embedding-3 / sentence-transformers / BGE。

# ============================================
# 性能优化
# ============================================
数据库慢查询怎么办
开启慢日志 (slow_query_log), 找出 > 100ms 的查询。
优化: 加索引 (B-Tree / 哈希)、改写 SQL、避免 SELECT *、分页优化 (游标分页)。
分库分表: 单表 > 5000 万行, 水平拆分 (按用户 ID hash) 或垂直拆分 (按业务)。
系统卡顿如何排查
Top 命令: 看 CPU 占用, 高则找热点线程 (jstack)。
iostat: 看磁盘 IO, 高则考虑 SSD 或加缓存。
free -m: 看内存, 低则加内存或优化 JVM (-Xmx)。
JVM Full GC 频繁
原因: 大对象、内存泄漏、堆太小。
解决: jmap + jhat 分析堆, 找内存泄漏点; 调 -Xmx; 优化代码避免大对象。
工具: MAT (Memory Analyzer) / VisualVM / GCEasy.io。

# ============================================
# AI 模型
# ============================================
什么是 Transformer
Transformer 是 2017 年 Google 提出的深度学习架构,基于自注意力机制。
核心: Self-Attention (Q/K/V) + 位置编码 + Feed Forward + 残差连接。
应用: BERT (Encoder) / GPT (Decoder) / T5 (Encoder-Decoder)。
什么是 GPT
GPT = Generative Pre-trained Transformer, 生成式预训练 Transformer。
训练: 大量文本无监督预训练 + 任务微调 (SFT) + RLHF 人类反馈强化学习。
代表: GPT-3 / GPT-4 / Claude / LLaMA / Qwen。
什么是 BERT
BERT = Bidirectional Encoder Representations from Transformers, 双向编码器。
预训练任务: 掩码语言模型 (MLM) + 下一句预测 (NSP)。
应用: 文本分类、问答、命名实体识别、搜索。
什么是 LoRA
LoRA = Low-Rank Adaptation, 低秩适应微调技术。
原理: 冻结原模型权重, 在每层加低秩矩阵 (A×B) 训练, 大幅减少参数量。
优点: 显存节省 3-10 倍, 适合大模型微调。

# ============================================
# 系统设计
# ============================================
如何设计短链系统
生成算法: Hash (原 URL) + Base62 编码 / Snowflake ID。
存储: 短链 → 原 URL 映射 (Redis + MySQL 双写)。
301/302 重定向 + 缓存 (CDN) + 预生成 (预热池)。
QPS 100 万: 100 台机器, 每台 1 万 QPS, 内存缓存 99% 命中。
如何设计秒杀系统
前端: 按钮防抖 + 验证码 + 排队页。
后端: Redis 预扣库存 (decr 原子) + MQ 异步下单 + MySQL 最终一致性。
防超卖: 乐观锁 (version) / 悲观锁 / Redis Lua 脚本。
限流: 令牌桶 (Sentinel) + 用户级 + IP 级。
如何设计消息队列
选型: Kafka (高吞吐) / RabbitMQ (复杂路由) / RocketMQ (事务消息)。
保证: 消息不丢 (ack + 重试 + 持久化) + 不重复 (幂等 + 唯一 ID) + 顺序 (partition key)。
监控: 消息积压 (lag) + 消费延迟 + 失败率。

# ============================================
# 容器化
# ============================================
什么是 Docker
Docker 是容器化引擎, 把应用 + 依赖打包到标准化单元 (镜像), 跨环境运行。
核心: 镜像 (image) / 容器 (container) / 仓库 (registry) / Dockerfile。
优点: 一次构建到处运行, 资源隔离, 启动秒级。
Docker 和虚拟机区别
VM: 硬件虚拟化, 启动 GB 级, 跑完整 OS, 隔离强。
Docker: 操作系统虚拟化, 启动 MB 级, 共享 OS 内核, 启动快。
资源: Docker 接近原生, VM 有 hypervisor 开销 5-10%。
什么是 Kubernetes
K8s = 容器编排平台, 自动部署/扩缩容/运维容器化应用。
核心: Pod (最小单元) / Deployment (无状态) / StatefulSet (有状态) / Service (负载均衡) / Ingress (入口)。
能力: 自动扩缩 (HPA) / 自愈 (重启失败容器) / 滚动更新 / 配置管理 (ConfigMap)。

# ============================================
# 投资理财
# ============================================
如何理财
先存钱 (紧急备用金 3-6 个月生活费), 再保险 (重疾+医疗), 后投资。
资产配置: 股票/基金 30%, 债券/银行 50%, 黄金/保险 20%。
复利: 7% 年化 30 年, 1 万变 7.6 万。
什么是定投
定投 = 定期定额投资基金, 固定时间投固定金额。
优点: 摊平成本 (高买低卖平均), 适合上班族, 强制储蓄。
适用: 长期 (5 年+)、波动大的品种 (股票基金、指数 ETF)。
什么时候买基金
低估区 (PE < 历史 30% 分位) 多买, 高估区少买。
长期持有 > 短线交易, 频繁交易手续费高。
基金定投不需要择时, 越跌越买。

如何增肌
训练: 复合动作 (深蹲/硬拉/卧推) + 渐进超负荷 + 每个部位每周 2 次。

有氧 + 力量结合, 单纯有氧易反弹。
饮食: 热量缺口 300-500 kcal/天, 不要节食 (易反弹)。

如何跑步不伤膝
姿势: 前脚掌着地, 步频 180 步/分钟, 身体微微前倾。
装备: 缓震跑鞋, 跑前热身, 跑后拉伸。
循序渐进: 每周增量不超过 10%。

# ============================================
# 心理情感
# ============================================
如何处理焦虑
识别: 担忧、失眠、心跳快、肌肉紧张。
缓解: 4-7-8 呼吸法 (吸 4 秒、屏 7 秒、呼 8 秒), 冥想, 运动。
长期: 认知行为疗法 (CBT), 找到焦虑根源, 改变不合理信念。
如何走出失恋
允许悲伤: 难过是正常的, 给自己时间。
切断联系: 删微信/拉黑, 避免反复看对方动态。
转移注意: 工作/学习/运动/社交, 重新建立生活节奏。
如何处理失眠
规律作息: 每天同一时间睡/起, 包括周末。
睡前准备: 远离手机 (蓝光抑制褪黑素), 泡脚/喝牛奶。
环境: 黑暗、安静、凉爽 (18-22°C), 床只用于睡觉。

# 美食烹饪
# ============================================
怎么做蛋炒饭
米饭 (隔夜饭最佳) 1 碗 + 鸡蛋 2 个 + 葱花 + 盐/酱油。
步骤: 鸡蛋打散, 热油下蛋液快速滑散, 加米饭翻炒 2 分钟, 加调料。
要点: 大火快炒, 米饭颗粒分明, 蛋香包裹。
怎么做番茄炒蛋
番茄 2 个 (切块) + 鸡蛋 3 个 (打散) + 葱蒜 + 糖/盐。
步骤: 先炒蛋至凝固盛出, 再炒番茄出汁, 加糖中和酸味, 倒回蛋翻匀。
要点: 糖提鲜, 蛋要嫩, 汤汁拌饭一绝。
怎么做可乐鸡翅
鸡翅 10 个 (划刀) + 可乐 1 罐 + 生抽/老抽/姜片/八角。
步骤: 鸡翅焯水, 煎至金黄, 加调料 + 可乐没过鸡翅, 中火炖 20 分钟收汁。
要点: 大火收汁, 色泽红亮, 甜咸适中。

# ============================================
# 编程实践
# ============================================
什么是代码评审
Code Review = 团队成员互相检查代码, 提高代码质量 + 知识共享。
关注: 可读性 / 可维护性 / 性能 / 安全 / 风格。
工具: GitHub PR / GitLab MR / Gerrit / Phabricator。
什么是 TDD
TDD = Test-Driven Development, 测试驱动开发。
流程: 红 (写失败的测试) → 绿 (让测试通过) → 重构 (优化代码)。
优点: 高覆盖率, 设计先于实现, 重构有信心。
什么是敏捷开发
敏捷 = 迭代 + 增量 + 拥抱变化, 4 大价值观 + 12 原则。
框架: Scrum (迭代 + 站会 + 评审) / Kanban (看板 + WIP 限制) / XP (结对 + TDD)。
工具: Jira / Confluence / Slack / 钉钉/飞书。

# ============================================
# 数据分析
# ============================================
如何做用户画像
维度: 基本 (年龄/性别/地域) + 行为 (访问/购买/停留) + 心理 (兴趣/价值观)。
方法: 聚类 (K-Means) / 决策树 / RFM 模型 (最近购买/频率/金额)。
应用: 精准营销 (千人千面) + 产品优化 + 风险控制。
什么是 A/B 测试
A/B 测试 = 将用户随机分两组, 体验不同方案, 比较效果。
要素: 假设 + 流量分配 (50/50) + 关键指标 (转化率/点击率) + 统计显著性。
工具: Google Optimize / 吆喝科技 / 自研平台。
如何看 PV/UV
PV (Page View) = 页面浏览量, 一次访问多次浏览累加。
UV (Unique Visitor) = 独立访客数, 同一用户一天内只算一次。
PV/UV = 人均浏览页数, 反映用户粘性。

# ============================================
# 运维监控
# ============================================
Prometheus 是什么
Prometheus 是开源监控系统, 时序数据库 + 拉取模式 + PromQL 查询。
核心: Metrics (指标) + Labels (标签) + Alertmanager (告警)。
生态: Grafana (可视化) + Node Exporter (主机) + cAdvisor (容器)。
ELK 是什么
ELK = Elasticsearch + Logstash + Kibana, 日志收集分析平台。
流程: Logstash 收集解析 → ES 存储索引 → Kibana 可视化查询。
替代: EFK (Fluentd) / Loki (轻量) / Splunk (商业)。
什么是 SRE
SRE = Site Reliability Engineering, 站点可靠性工程师。
职责: 保障服务可用性 (SLO/SLI/SLA) + 故障响应 + 性能优化 + 自动化。
核心: 错误预算 (Error Budget) + On-Call + Runbook + Postmortem。

# ============================================
# 汽车
# ============================================
怎么选第一辆车
需求: 通勤/家用/长途, 5 座/7 座, 油车/电车/混动。
预算: 落地价 = 裸车价 × 1.1 (购置税) + 保险 (5-8 千) + 上牌 (500)。
推荐: 10 万级 (卡罗拉/轩逸) / 15 万级 (思域/速腾) / 20 万级 (凯美瑞/雅阁)。
油电怎么选
电车: 用车成本低 (电费 < 油费 1/5), 加速强, 智能化高, 但续航焦虑 + 充电慢。
油车: 加油快, 续航长, 技术成熟, 但油价高 + 限行 (部分城市)。
混动: 综合两者优点, 短途用电 + 长途用油。

# ============================================
# 商务谈判
# ============================================
谈判技巧
1. 充分准备: 知己 (底线/期望) 知彼 (需求/痛点)。
2. 先报价: 谁先报价谁占优, 锚定效应。
3. BATNA: 找好最佳替代方案, 才有底气说 NO。
4. 倾听: 让对方多说, 了解真正需求。
5. 互惠: 主动让步, 换对方让步。
如何砍价
1. 找瑕疵 (轻微划痕/小问题), 作为砍价理由。
2. 货比三家, 拿到最低报价, 让商家 match。
3. 凑单 (满减 + 折扣 + 赠品), 总额更低。
4. 现金支付, 部分商家可减 5-10%。

# 求职进阶
# ============================================
如何选 Offer
1. 行业: 朝阳 (AI/新能源) > 传统 (制造/零售), 决定长期发展。
2. 公司: 头部 (BAT/字节/美团) > 中型 (细分龙头) > 创业 (期权 vs 风险)。
3. 岗位: 核心业务 > 边缘部门, 直接创造价值。
4. 成长: 直属领导 (决定 80% 工作体验) > 平台大小。
5. 钱: 总包 (薪资+股票+补贴), 5 年 50% 增长。
如何转行
1. 找到目标岗位 JD, 提取 5-10 个核心技能。
2. 自学 + 项目实战 + 证书 (PMP/AWS/CDA)。
3. 内部转岗 > 外部跳槽, 风险小。
4. 人脉: 行业社群 + 知乎 + 脉脉, 内推机会多。

# ============================================
# 商业
# ============================================
什么是商业模式
商业模式 = 创造/传递/获取价值的方式。
核心要素: 价值主张 + 客户细分 + 渠道 + 客户关系 + 收入流 + 关键资源/活动/伙伴 + 成本结构。
画布: Business Model Canvas (Osterwalder), 9 宫格一目了然。
什么是 SaaS
SaaS = Software as a Service, 软件即服务。
特点: 订阅制 (月/年费) + 云端部署 + 多租户 + 持续迭代。
指标: MRR (月经常性收入) + ARR (年经常性收入) + Churn (流失率) + LTV (客户终身价值) + CAC (获客成本)。
什么是 OKR
OKR = Objectives and Key Results, 目标与关键结果。
O (目标): 方向性, 定性, 有挑战性。
KR (关键结果): 可量化, 3-5 个, 衡量 O 的完成度。
周期: 季度 + 半年, 周/月跟踪进度。
